3.1 — DATABASE_URL CONFLICT FIX (sitecustomize.py):
   The .env file sets DATABASE_URL for Prisma, but anndata's pydantic-settings
   reads it as a SQLite path and crashes. Fix: create sitecustomize.py in
   Python site-packages that does:
     os.environ.pop("DATABASE_URL", None)
     os.environ.pop("DATABASE_URL_FILE", None)
   Also patches scverse_misc.Settings.settings_customise_sources to accept **kwargs
   (pydantic-settings 2.13+ passes keyword args that scverse_misc doesn't expect).
   Suppress all FutureWarning, DeprecationWarning, UserWarning, RuntimeWarning.
   Set PYTHONWARNINGS=ignore.

3.2 — PROJECT_ROOT RESOLUTION (critical on Windows):
   NEVER use hardcoded paths like "/home/z/my-project". Instead:
     const PROJECT_ROOT = process.cwd();
   Or for Next.js standalone (where cwd is .next/standalone/):
     const PROJECT_ROOT = path.resolve(__dirname, '..', '..', '..');
   This must be consistent across ALL route files. Apply to:
   route.ts, chunk/route.ts, assemble/route.ts, report-pdf/route.ts,
   batches/route.ts, calibration/route.ts.

3.3 — CHUNKED UPLOAD RACE CONDITION (critical):
   When uploading in parallel (MAX_PARALLEL > 1), chunk 0's cleanup code
   (unlink the .bin file) can delete chunks already written by a parallel worker.
   FIX: Set MAX_PARALLEL = 1 (sequential), and NEVER unlink on chunk 0.
   Each uploadId is unique, so stale cleanup is unnecessary.
   Add stale session cleanup (delete .bin files older than 2 hours).

3.4 — PDF RENDER None TYPE CRASH:
   qr.get("cross_check_warning", "") returns None when the key exists with null value.
   None[:80] throws TypeError. FIX: use (qr.get(...) or "")[:80] everywhere.
   Apply to ALL string slicing in render_qc_pdf.py and any PDF generation code.

3.5 — SERVER CRASH PROTECTION:
   Add src/instrumentation.ts with:
     process.on('uncaughtException', (err) => console.error('UNCAUGHT:', err));
     process.on('unhandledRejection', (err) => console.error('UNHANDLED:', err));
   This prevents the server from dying on stray async errors.
   The handler must NEVER call process.exit().

3.6 — MEMORY GUARDS (for low-RAM machines):
   In API routes, check free RAM before spawning Python:
     import { freemem } from 'os';
     const freeMB = freemem() / 1e6;
     if (freeMB < 400) return NextResponse.json({status:'error', message:'Insufficient RAM'}, {status:507});
   In qc_fast.py, set MAX_CELLS = 500 (not 10000) and use backed mode for files > 50MB.
   Use gc.collect() after preprocessing to free memory.
   Set Node heap: NODE_OPTIONS="--max-old-space-size=256" to leave RAM for Python.

3.7 — SVM PROBABILITY DEPRECATION:
   sklearn 1.9+ deprecated SVC(probability=True). Instead, remove probability=True
   and use CalibratedClassifierCV(SVC(), method="sigmoid", cv=StratifiedKFold) to
   get predict_proba. If calibration fails, fall back to decision_function + Platt sigmoid:
     d = est.decision_function(X)
     p = 1 / (1 + np.exp(-d))
   Wrap in try/except — silent fallback, no warning logged.

3.8 — MLP CONVERGENCE WARNING:
   sklearn's MLPClassifier prints "Maximum iterations reached" warning when max_iter
   is too low. FIX: set max_iter = max(2000, mlp_epochs * 20) and rely on
   early_stopping=True + n_iter_no_change=10 to do the actual stopping.

3.9 — TURBOPACK PATH.JOIN WARNING:
   Next.js 16's Turbopack flags dynamic path.join() calls as "tracing the whole project".
   FIX: add /*turbopackIgnore: true*/ comment inside path.join():
     path.join(/*turbopackIgnore: true*/ PROJECT_ROOT, 'results')

3.10 — DEFENSIVE .toFixed() IN REACT:
   Backend may return undefined for fields like psc_probability. Calling

     const pscProb = typeof c?.psc_probability === 'number' ? c.psc_probability : 0;

3.11 — BACKTICK BALANCE IN JSX TEMPLATE LITERALS:
   className={`text-sm font-bold ${condition ? 'a' : 'b'}} must close with }`}>
   NOT }}>. A missing backtick causes "Expected '</', got 'ident'" build error.
   Verify backtick count is even in every .tsx file.

3.12 — WINDOWS PATH COMPATIBILITY:
